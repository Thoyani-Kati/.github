

## About

I am a Computer Science and Information Technology student and software engineer interested in understanding how software systems work from the ground up.

My work sits primarily around **backend engineering, application architecture, databases, and full-stack web development**.

I enjoy taking an idea from a problem or concept through:

**System design → implementation → testing → deployment → iteration**

I am particularly interested in software that is not simply technically interesting, but actually useful.

### KATCODE Projects

A project-based development environment currently under development.

The system is designed around the idea of turning software projects into structured engineering workflows through:

- Project selection
- Milestones
- Feature branches
- GitHub integration
- Code submissions
- Automated tests
- Test execution logs
- Submission history

The goal is to create an environment where building software becomes a structured engineering process rather than simply writing code.
